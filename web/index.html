账号安全提示

安全模式已开启：同一时间只处理 1 个任务，任务间隔至少 3 秒。任何第三方客户端都无法绝对保证账号零封禁风险；请使用自己的账号、低频使用，并遵守 B 站用户协议。

安全模式已关闭（BILI_SAFE_MODE=false）：并发和请求间隔不再受限，账号风险会明显上升。建议改回安全模式；任何第三方客户端都无法绝对保证账号零封禁风险。

如何获取 SESSDATA
  1. 在浏览器中登录 bilibili.com。
  2. 打开开发者工具 → Application / Storage → Cookies → https://www.bilibili.com。
  3. 找到 SESSDATA，复制它的值（也可以复制整行 Cookie），粘贴到上方输入框。

Cookie 等同于登录凭据，请勿分享、截图或提交到 Git；不需要时可在上方退出登录。

本地存储

通过本界面登录时，只保留 SESSDATA 与匿名设备标识（丢弃 bili_jct 等写操作凭据），写入 0600 权限文件；仅随 B 站 API 请求发送，不会发送给音频 CDN。

Cookie 只保存在本机，仅随 API 请求发送给 B 站；本工具不保存 B 站密码。
